What I need

A useful first message

You do not need a perfect brief. A few honest details are enough to work out the next sensible step.

01

Project type

New website, redesign, landing page, portfolio, booking form, catalogue, or custom Django app.

02

Size and features

Rough page count, forms, admin editing, blog, gallery, products, payments, SEO, or hosting help.

03

Content readiness

Logo, text, photos, domain, current website link, brand notes, and anything that still needs help.

04

Budget and timing

A rough budget range and whether the project is urgent, flexible, or still being explored.
